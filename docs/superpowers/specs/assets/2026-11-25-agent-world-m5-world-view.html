        Design notes

        The idea. The street is the plan. Left to right is the order of stages, so you read the initiative like a walk down one road: built blocks behind you, scaffolding where work is happening, fenced lots ahead. Nothing on the street is decoration: each piece is a ledger record, and the rows under the faceplate list the same records.

        • Trust is visible as material. A floor someone reported as done is built but dark. A floor only lights when evidence verifies it (a trusted check or the owner). A flag goes up only on the owner's gate verdict. So "Claude says done" and "proven" never look alike.
        • Time isn't drawn. There are no dates in the ledger, so the street has no clock, no day cycle and no traffic. Night is a theme the page names as one, and it doesn't change meaning.
        • Freshness takes things away. Scaffolding and a worker show only within a session's 2-minute window. After that the worker becomes an outline with "No report since", and the scaffolding comes down.
        • One motion. When a run finishes, its van pulls away and that floor's scaffolding comes down. That's the only animation, and reduced motion snaps it.
        • Density. Planned stages are narrow lots with their full names in the ruler, the rows and the inspector. Below about 1,100 px the street scrolls sideways in a focusable region that opens on the current stage, rather than shrinking the labels.
        • Agent World never acts. Every action links to the Pi Hub Missions page that owns the record (/missions/a34#…). That's the A35 rule that Agent World is never a source.

        Differences from §10.4, to decide:

        • A blocked task gets hazard tape on its floor. §10.4 only draws blocks as road barriers between entities; a task blocked by something outside the plan had no mark.
        • A reported done floor is drawn as built but dark. §10.4 only says what lit means.
        • Gates are drawn on the street as arches, and the district ruler under the street names each stage and its gate in HTML, so stage text is never painted into the art.
        • The inspector is the kit sheet that A35 §10.2 needs. It's drawn here with tokens and needs a kit PR first.
