# Rules for coding agents in LocalAI

These hold for every agent (Claude Code, Codex, others).

- **Read `CLAUDE.md` in this folder first.** It holds this repository's rules (how changes land, local CI, the ship
  gate, contracts that tests check); they apply to every agent, not only Claude.
- **Read the Home Platform design contract before any UI work**: appliance-ui `DESIGN.md`
  (https://github.com/azmusgb/appliance-ui/blob/main/DESIGN.md). Read it at the start of the task, not from memory or
  from this summary. Pi Hub's baseline and its approved amendments (A4, A6, A7 and later) win where they differ. If you
  can't open it (no network, no access), say so and stop before changing a screen.
